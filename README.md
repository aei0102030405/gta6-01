# Make GTA 6 — open-world crime game

An original open-world crime game for [make.fun](https://make.fun/bounty/gta6-01)'s gta6-01 bounty. Playable in a desktop browser from static files, no network request, keyboard and mouse. A city to explore on foot and by car, traffic and pedestrians, cars to steal, a wanted level and police, missions and a story, combat, a HUD with a minimap, a start screen and a save.

Run: `node serve.ts`, then open http://localhost:8080
